# Simulation evidence

transcript.txt is the complete original Vivado batch log, including five XSim suites, synthesis and implementation. Results retains the identical original log and separate PASS files. Other *_transcript.txt files are earlier local Icarus/reference runs, not physical board evidence.

waveform.vcd and waveform_transcript.txt were generated by an additional Icarus execution of Testbench/tb_waveform.sv against the committed RTL and frozen goldens. Twelve directed cases across both banks check hidden bits, all scores, class, margin, model tag and exact 5/21-cycle latency. waveform.png plots real VCD transitions for input 0222 under the two profiles. waveform_measurements.csv samples 2 ns after each rising edge; subtract 2 ns for edge timestamps, with latency differences unchanged.

Reproduce the extra trace from this project root (Icarus installed):

```sh
iverilog -g2012 -s tb_waveform -o Simulation/waveform.vvp RTL/bnn_math_pkg.sv RTL/bnn_parallel.sv RTL/bnn_folded.sv Testbench/tb_waveform.sv
vvp Simulation/waveform.vvp > Simulation/waveform_transcript.txt
mv waveform.vcd waveform_measurements.csv Simulation/
```

The default DATA_DIR in this additional testbench must name the project root. Running from this root with DATA_DIR="." resolves the model and golden files. The five main suites are automated by Python/run_open_source_tests.py or RUN_PROJECT5.cmd/XSim. The trace PNG can be replotted using Python/plot_waveform.py; matplotlib is an optional plotting dependency.
