# Earlier source-pack records

These files preserve the original preparation and repair records from before
the successful Vivado build and physical board verification. Their
pending-build or pending-board statements describe that earlier state.

`source_pack_SHA256SUMS.txt` inventories the original unpacked repair pack with
its original filenames. It is not a checksum list for the current repository
folder. The current package is inventoried by the experiment-root
`SHA256SUMS.txt` and `Documentation/FILE_MANIFEST.json`.

Use the current experiment README, verification scope and submission checklist
for the present status. The report outline is retained as a historical template;
the completed report is `Documentation/Project4_NN_Report.pdf`.
